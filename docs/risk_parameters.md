## 7. Emergency Procedures

### If Agent Goes Rogue
```bash
# Manual kill switch from terminal
curl -X POST http://localhost:3000/api/agents/kill -d '{"agentId":"fx"}'

# Or edit agents_db.json directly
# Set status: "KILLED" for the agent
```

### If System Unresponsive
```bash
# Kill all node processes
pkill -f "node"
pkill -f "tsx"

# Kill Python agents
pkill -f "python"
```

### Reset After Kill Switch
```typescript
import { KillSwitch } from './src/lib/engine/risk/KillSwitch';
KillSwitch.reset('fx', 'Manual recovery after incident');
```
