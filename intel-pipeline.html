🔧 Suggested Improvements

✅ Implemented — Weights & Regime Done

  • Weight rebalance: Added FREE_SOURCES_ONLY=true env var. When set, premium weights → 0 and free sources absorb full 100% (F&G 25%, Funding 22%, Market 20%, Social 20%, Econ 13%). One line in .env.
  • Regime deduplication: detectRegime() extracted to src/lib/intel/regime.ts. Both adapter.ts and preflight/route.ts now import from there — thresholds unified at 0.55.

✅ Implemented — Auditor & Sources Done

  • TheAuditor deterministic: Replaced Math.random() with logic driven by event_context.highImpactDuringTrade and intel_attribution.alignment. News critiquest overturned only when the calendar shows no high-impact event. F-grade disputed only when intel was ALIGNED but still lost.
  • Reddit WSB: reddit.com/r/wallstreetbets/new/.rss — direct feed, no proxy, polls every 5m. Retail sentiment + short squeeze coverage.
  • SEC EDGAR 8-K: sec.gov/cgi-bin/browse-edgar?output=atom — real-time 8-K filings, every 5m. Catches MicroStrategy, Coinbase, corporate crypto treasury announcements.
  • Per-symbol keywords: ECB, Lagarde, Eurozone → EURUSD. BOE, Bailey, Brexit, Sterling, UK CPI → GBPUSD. Added as symbol-scoped rules in KEYWORD_RULES alongside existing crypto rules.

🟠 Architecture — Still Open Medium

  • Grid strategy: Only strategy with no intel integration — add direction veto at minimum.
  • Symbol hardcoding: IntelAdapter created with 'BTCUSD' hardcoded in manager.ts. Should create adapters per strategy's actual symbol.
  • No RSS fallback log: Social feed silently drops account if all proxies fail — add a visible health indicator per account.
  • Confidence cap: Adapter tops out at Math.min(1, signalCount / 6). With 7 free sources now live, consider tuning denominator from 6 → 5.

🟡 Quick Wins — Still Open Low

  • Auto weight rebalancing: Script that reads computeIntelAccuracy() and nudges INTEL_WEIGHT_* in .env toward better-performing sources.
  • StockTwits public API: Free trending tickers endpoint — no key, would add equities retail sentiment.
  • CoinGecko trending: Free /api/v3/search/trending — which coins are being searched, strong momentum proxy.
  • Signal age indicator: Show how stale each signal is in UI (e.g. "12m ago") — important when sources poll infrequently.
  • Intel dashboard card: Add Social Feed as visible card on /intel page — last tweet summary + proxy health per account.
